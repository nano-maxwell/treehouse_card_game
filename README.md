# Treehouse Card Game

A higher-or-lower mobile card game built with Flutter.

Select one of nine card piles, predict whether the next card will be higher or lower, and try to make it through the deck.

## Features

- Nine-pile higher-or-lower gameplay
- Animated card reveals and movement
- No advertisements, in-app purchases, or data collection
- Original card artwork and app icon
- Works completely offline
